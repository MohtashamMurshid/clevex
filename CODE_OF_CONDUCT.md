# Code of conduct

clevex follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming, be respectful, give and accept constructive feedback
gracefully, and focus on what's best for the community. Harassment,
discrimination, and personal or political attacks aren't tolerated in issues,
pull requests, discussions, or any other project space.

## Reporting

To report unacceptable behavior, contact the maintainers privately through
GitHub (for example, a private vulnerability report marked "conduct", or a
direct message to a maintainer). Reports are handled confidentially. The
maintainers may remove content or ban contributors who break this code, as the
Contributor Covenant's enforcement guidelines describe.
